# Welcome to MiracleWM

This repository contains the configuration and documentation for my **MiracleWM** setup on Arch Linux. 

MiracleWM is a modern, tiling Wayland compositor that provides a clean, efficient, and highly customizable desktop experience. This specific configuration is themed around a luxurious **Golden & Black** aesthetic.

## ✨ Features
- **Tiling Window Management**: Automatic window tiling with customizable layouts.
- **Golden Theme**: Custom `#EFBF04` gold accents across Waybar, Rofi, and window borders.
- **Waybar Integration**: Dedicated `waybar5` configuration for system monitoring and workspace management.
- **Rofi Launcher**: Custom-styled application launcher and power menu.

Explore the navigation menu to find installation guides, keybindings, and theming details!
