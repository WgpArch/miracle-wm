# Keybinds Reference

Here are the exact keybindings configured in `config.yaml` for this MiracleWM setup.  
*(Note: `Super` refers to the Windows key).*

| Action | Keybinding |
| :--- | :--- |
| **Open Terminal** | `Super + Return` |
| **Close Window** | `Super + q` |
| **Go to Workspace 1-9** | `Super + 1` through `9` |
| **Go to Workspace 10** | `Super + 0` |
| **Go to Workspace 11** | `Super + minus` |
| **Full Screenshot** | `Print` |
| **Area Screenshot** | `Super + Print` (uses `slurp` & `grim`) |

*For a complete list of workspace rules and gaps, refer to `~/.config/miracle-wm/config.yaml`.*
