# Waybar Configuration

This setup uses a dedicated **Waybar** configuration (stored in `waybar5`) tailored for MiracleWM.

## Features
- **Golden Theme**: `#EFBF04` accents with solid black backgrounds and rounded blocks.
- **Modules**: Workspaces, Clock, Weather, PulseAudio, CPU, Memory, Battery, and System Tray.

## Files
- `config.jsonc`: Module layout and behavior.
- `style.css`: Visual styling (colors, borders, rounded corners).
